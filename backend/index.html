PATCH/discounts/{product_id}

Updates the discount details for a product.

Path parameter

product_id — ID of the product.

Request body

{
  "product_id": "47898d22-3b2a-4b97-9aac-048ae01a5bda",
  "amount": 1850,
  "start_date": "2026-09-12 10:44:05.122+00",
  "end_date": "2026-09-20 06:44:05.122+00"
}

cURL

curl -X PATCH "https://billingsys-react-5514a.containers.snapdeploy.app/api/discounts/PRODUCT_ID" \
  -H "Content-Type: application/json" \
  -d '{"product_id":"47898d22-3b2a-4b97-9aac-048ae01a5bda","amount":1850,"start_date":"2026-09-12 10:44:05.122+00","end_date":"2026-09-20 06:44:05.122+00"}'

POST/insights/

Records a view event for a product and increments its view total.

Request body

{
  "product_id": "17b86a99-8c25-42cb-b4b6-c7eb35166bef",
  "total_views": 26
}

cURL

curl -X POST "https://billingsys-react-5514a.containers.snapdeploy.app/api/insights/" \
  -H "Content-Type: application/json" \
  -d '{"product_id":"17b86a99-8c25-42cb-b4b6-c7eb35166bef","total_views":26}'
